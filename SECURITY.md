# Política de segurança

Este repositório publica conteúdo estático (site em GitHub Pages) do ecossistema Projeto Industrial.

## Como relatar um problema de segurança

Use o relato privado do GitHub: aba **Security** → **Report a vulnerability**.
Não abra issue pública com detalhes de vulnerabilidade nem inclua segredos reais (chaves, tokens, senhas) em issues, commits ou anexos.

## Escopo

Falhas no código do site, links ou arquivos publicados que exponham dados indevidos ou permitam execução de código no navegador de quem visita o site.
Os dados e conteúdos são didáticos ou de referência e não substituem projeto, norma ou parecer técnico.
